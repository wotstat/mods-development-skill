# Существующий мод и перенос на новый патч

Читайте этот файл для готового проекта, исправления бага, новой функции или адаптации под новую версию клиента.

Для обычных изменений используйте [рабочий цикл](../SKILL.md#рабочий-цикл). Ниже — особенности диагностики и переноса между патчами.

## Диагностика

Начинайте с конкретного сбоя и относящегося к нему traceback. Для быстрой проверки используйте REPL-хвост, для большого поиска — `python.log` по [правилам чтения логов](runtime-validation.md#логи-целевая-выборка).

## Patch migration

При переносе начните с воспроизводимого сбоя или затронутого API в исходниках целевого клиента. Старый checkout и `git diff <old>..<new> -- <paths>` используйте, если сравнение помогает понять изменение; поиск старого snapshot описан в [evidence-and-intake.md](evidence-and-intake.md). Не обходите все используемые модом символы без конкретной причины.

Исправьте соответствующий adapter/hook с учётом нового контракта и проверьте сценарий в клиенте. Rename сам по себе не доказывает сохранение семантики. Если API разошёлся между продуктами, реализуйте подтверждённые различия в compatibility-коде.

## Добавление функции

Если разрозненные обращения к API мешают изменению, выделите минимальный adapter вокруг конкретного нестабильного контракта. При изменении hook учитывайте частично инициализированные и уничтоженные объекты; основные требования к patches приведены в [SKILL.md](../SKILL.md#рабочий-цикл).

## Проверка регрессий

Для готовности миграции/релиза дополнительно проверьте исходный рабочий сценарий и каждую заявленную цель. Утверждение «адаптировано под патч» требует проверки в новом клиенте. Если клиента нет, сообщите обычными словами: пакет собран, поведение на новом клиенте не проверено.

Если существующий build компилирует Python in-place, исправьте это минимально: перенесите compile/package inputs в staging или задайте явные output paths. Не маскируйте проблему cleanup-командой по исходному `res/` и не удаляйте уже существующие пользовательские artifacts без отдельного согласования.
